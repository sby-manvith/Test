# Test

A dummy project to experience and explore the functionalities of GitHub.

## Purpose

This repository serves as a sandbox for learning and experimenting with GitHub features, including:

- **Version Control** – Committing, branching, and merging code
- **Pull Requests** – Opening, reviewing, and merging pull requests
- **Issues** – Creating and tracking issues
- **GitHub Actions** – Setting up CI/CD workflows
- **Releases** – Tagging and publishing releases
- **GitHub Copilot** – AI-assisted coding and code review

## Getting Started

Clone the repository:

```bash
git clone https://github.com/sby-manvith/Test.git
cd Test
```

Run the sample script:

```bash
python hello.py
```
